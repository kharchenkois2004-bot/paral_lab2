II. Описание программ

Программа A

Работает с PNG изображением (библиотека lodepng) при помощи нескольких потоков (библиотека OPENMP).
1. Получает на вход PNG изображение (imageName).
2. Для каждого пикселя вычисляет интенсивность (среднее значение по каналам RGB) и сравнивает с пороговым значение (threshold).
3. Пиксели со значением меньше порогового окрашивает в темный цвет, пиксели со значением больше - в светлый (цвета различается для каждого потока).
4. Полученный результат сохраняет в файл.
5. Проводит операцию эрозии для каждого пикселя изображения с указанным шагом (step).
6. Полученный результат сохраняет в файл.
7. Записывает в лог параметры и время выполнения.

Программа Б

Работает с PNG изображением (библиотека lodepng) при помощи нескольких потоков (библиотека OPENMP).
1. Получает на вход PNG изображение (imageName).
2. Проводит операцию переноса пикселей по оси X (stepX) и по оси Y (stepY).
3. Исходные пиксели, оставшиеся пустыми, закрашивает (187, 38, 73).
4. Полученный результат сохраняет в файл.
5. Проводит операцию свертки с заданным фильтром для пикселей изображения.
6. Полученный результат сохраняет в файл.
7. Записывает в лог параметры и время выполнения.

3. Зарузить PNG-изображения в папку input/.
4. Выбрать нужный main_*.cpp файл.
Перечислить имена всех изображений (имена файлов без указания формата) в массиве images.

6. Указать нужное кол-во потоков в поле hreadCount.
7. Выбрать нужный режим вывода дополнительной информации в консоль при помощи поля DEBUG (по умолчанию false).
8. Настроить остальные параметры программы
