2. Описание программ
Программа A
Работает с PNG изображением (библиотека lodepng) при помощи нескольких потоков (библиотека OPENMP).
а) Получает на вход PNG изображение (imageName).
б) Для каждого пикселя вычисляет интенсивность (среднее значение по каналам RGB) и сравнивает с пороговым значение (threshold).
в) Пиксели со значением меньше порогового окрашивает в темный цвет, пиксели со значением больше - в светлый (цвета различается для каждого потока).
г) Полученный результат сохраняет в файл.
д) Проводит операцию эрозии для каждого пикселя изображения с указанным шагом (step).
е) Полученный результат сохраняет в файл.
ж) Записывает в лог параметры и время выполнения.

Программа Б
Работает с PNG изображением (библиотека lodepng) при помощи нескольких потоков (библиотека OPENMP).
а) Получает на вход PNG изображение (imageName).
б) Проводит операцию переноса пикселей по оси X (stepX) и по оси Y (stepY).
в) Исходные пиксели, оставшиеся пустыми, закрашивает (187, 38, 73).
г) Полученный результат сохраняет в файл.
д) Проводит операцию свертки с заданным фильтром для пикселей изображения.
е) Полученный результат сохраняет в файл.
ж) Записывает в лог параметры и время выполнения.
